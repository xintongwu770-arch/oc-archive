# OC ARCHIVE 网站模板

一个空的整体框架，用来收纳多个世界观、角色档案、角色关系图和故事/短打。
目前所有内容都是占位示例文字，替换成你自己的设定即可使用。

## 目录结构

```
oc-website/
├── index.html        首页 —— 世界观总览网格
├── world.html         世界观详情页（角色档案 / 关系图 / 相关故事 三个标签页）
├── character.html     角色详情页
├── story.html          单篇故事/短打阅读页
├── drabbles.html       所有"短打"汇总页
├── css/
│   ├── theme.css        颜色、字体、圆角、间距等设计变量 —— 想换风格改这里
│   └── style.css         页面结构/布局样式 —— 一般不用改
├── js/
│   ├── data.js           ★ 所有内容都在这里：世界观、角色、关系、故事
│   └── main.js            渲染逻辑，一般不用改
└── images/                以后放角色立绘、世界观封面图的地方（先空着）
```

## 怎么加内容

**只需要编辑 `js/data.js` 一个文件**，按已有的示例格式复制粘贴、改文字即可：

- `WORLDS` 数组 → 新增一个世界观
- `CHARACTERS` 数组 → 新增一个角色（`worldId` 要填对应世界观的 `id`）
- `RELATIONS` 数组 → 新增一条角色关系（`from`/`to` 填角色 `id`）
- `STORIES` 数组 → 新增一篇故事或短打（`type` 填 "短打" 会自动出现在短打汇总页；`worldId` 留空 `""` 表示不属于特定世界观）

改完保存，直接刷新网页就能看到效果，不需要构建/编译。

以后想放角色立绘：把图片放进 `images/` 文件夹，再把角色数据里的 `portrait` 字段改成图片路径，比如 `"images/角色甲.png"`，我再帮你把肖像占位框换成真图片显示逻辑。

## 怎么换设计风格

打开 `css/theme.css`，最上面是一组变量（颜色、字体、圆角、间距），改这些数值就能整体换肤，不用动其他任何文件。比如：

```css
--color-bg: #14151a;      /* 页面底色，换成你想要的颜色 */
--color-accent: #c94f4f;  /* 主强调色 */
--font-display: ...;      /* 标题字体 */
```

如果想要浅色版本，把 `<html>` 标签加上 `data-theme="light"` 属性即可（`theme.css` 里已经写好了一套浅色变量，可以直接改数值）。

结构性的东西（卡片形状、间距大小、布局方式）在 `css/style.css` 里，如果只是想调颜色和字体，不需要碰这个文件。

## 关于角色关系图

现在是一个简易占位版：节点按圆形排列，可以拖动，点击跳转到角色档案页。逻辑在 `js/main.js` 的 `renderRelationGraph` 函数里。如果以后想要更复杂的力导向布局、分组、箭头方向等，告诉我，我再升级这部分。

## 部署到 GitHub Pages（免费）

1. 在 GitHub 新建一个仓库（比如 `my-oc-site`）。
2. 把这个文件夹里的所有文件上传上去（网页端拖拽上传，或用 Claude 桌面应用连接 GitHub 后请它帮你推送）。
3. 进仓库 Settings → Pages，Source 选 `main` 分支、根目录，保存。
4. 几分钟后，`https://你的用户名.github.io/my-oc-site/` 就能访问了。

如果之后想让 Claude 帮你继续开发（加数据、改样式、做新功能），把这个文件夹交给 Claude 桌面应用的 Code 功能就行，跟它说"这是我的OC网站项目，读一下 README.md 了解结构"。
