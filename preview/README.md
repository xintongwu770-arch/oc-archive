# OC 工作台预览

公开预览位于 `/preview/`，旧网站入口不受影响。

## 本机编辑

运行 `node preview/server.mjs`，打开 `http://127.0.0.1:4174/preview/`，点击「作者工作台」。

- 角色、城市、故事线、文章、关系、时间事件与立绘可编辑、新增。
- 草稿存放于 `.oc-studio/draft.json`；原图存放于 `.oc-studio/originals/`。该目录已加入 Git 忽略，服务器不提供它的静态访问。
- 自动保存只在本机工作台可用。服务器绑定回环地址，并检查 Host、Origin 和会话令牌。
- 「预览草稿」按公开规则过滤。`private` 内容不会写进 `published.json`；`reveal` 内容是可公开查看的剧透，不能当成保密存储。
- 「发布到本机预览」写入 `published.json`，保留上一版快照。不会自动发布 GitHub 或腾讯云。
- 上传原图后使用浏览器 Canvas 生成最长边 1400px 的 JPEG 展示图，发布时复制被引用的展示图。
- 完整 JSON 备份包含私人资料；公开导出不包含私人笔记、私人条目、私人章节、原图路径。
- 剧情时间轴初始为空：旧数据只有文章发布日期，不能据此确定剧情时间。作者可录入时期或顺序。

## 迁移与检查

首次迁移：`node preview/migrate.mjs`。它读取既有 `js/data.js`，内嵌 4 篇外部 Markdown 正文，保存全部 39 位角色、9 条故事线、8 篇文章、12 张额外立绘。

**已有编辑后不要再次运行迁移命令**，它会覆盖公开预览的数据。

检查：`node preview/verify.mjs`。
